## Overview

**`TakaGo`** is a modern Mobile Financial Services (MFS) web application that delivers a secure, fast, and user-friendly digital financial experience. Built with **HTML, Tailwind CSS, DaisyUI, and Vanilla JavaScript**, it enables users to perform essential financial operations through an intuitive and responsive interface. The application supports core services such as adding money, cashing out, sending money, paying bills, claiming bonuses, and viewing transaction history with real-time balance updates and PIN verification.

## Features

* **Simple Login Interface** - Secure authentication with username and password
* **Home Dashboard** - View account balance and quick access to all services
* **Add Money** - Deposit funds into your TakaGo account
* **Cash Out** - Withdraw money with PIN verification
* **Money Transfer** - Send money to other users securely
* **Bill Payment** - Pay bills conveniently through the platform
* **Bonus Rewards** - Earn and track promotional bonuses
* **Transaction History** - Complete record of all financial activities
* **PIN Security System** - Every transaction requires PIN authentication for enhanced security
* **User-Friendly Interface** - Responsive design built with DaisyUI for an optimal experience across devices
